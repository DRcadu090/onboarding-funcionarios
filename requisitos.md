# Requisitos do Sistema — Plataforma de Onboarding

## 1. Requisitos funcionais

Os requisitos funcionais descrevem o que o sistema deverá permitir fazer.

**RF01 — Portal de boas-vindas:** o sistema deverá apresentar uma mensagem de boas-vindas para os novos funcionários.

**RF02 — Checklist de tarefas:** o sistema deverá permitir que o funcionário visualize e marque as tarefas concluídas durante o período de integração, acompanhando seu progresso.

**RF03 — Documentação:** o sistema deverá apresentar uma área com documentos, manuais e orientações importantes da empresa.

**RF04 — Reuniões e treinamentos:** o sistema deverá apresentar informações sobre reuniões e treinamentos dos funcionários.

**RF05 — Perguntas e respostas:** o sistema deverá oferecer um espaço para que os funcionários registrem suas dúvidas.

**RF06 — Feedback:** o sistema deverá permitir que os funcionários enviem opiniões sobre o processo de integração.

**RF07 — Salvamento de informações:** o sistema deverá salvar localmente no navegador as tarefas marcadas, dúvidas e feedbacks enviados, mantendo essas informações após a atualização da página.

## 2. Requisitos não funcionais

Os requisitos não funcionais descrevem características esperadas do sistema.

**RNF01 — Facilidade de uso:** as páginas deverão ser simples e fáceis de entender.

**RNF02 — Organização:** as informações deverão estar separadas em áreas para facilitar a navegação.

**RNF03 — Compatibilidade:** o site deverá poder ser acessado em navegadores atuais, tanto em computadores quanto em celulares.

**RNF04 — Legibilidade:** os textos e botões deverão ser apresentados de forma clara, facilitando a leitura e a utilização.

**RNF05 — Responsividade:** o layout deverá se adaptar a diferentes tamanhos de tela.

## 3. Situação atual

O sistema foi desenvolvido utilizando HTML, CSS e JavaScript. Atualmente, possui portal de boas-vindas, checklist interativo com contador e barra de progresso, área de documentos, informações sobre reuniões e treinamentos, espaço para envio de dúvidas e área de feedback.

As tarefas, dúvidas e opiniões enviadas ficam salvas no armazenamento local do navegador, permitindo que continuem disponíveis após atualizar a página.

## 4. Escopo do projeto

O projeto tem como objetivo oferecer uma plataforma simples para auxiliar novos funcionários durante o processo de integração com a empresa.

As funcionalidades desenvolvidas são voltadas à apresentação de informações, acompanhamento de tarefas, consulta de materiais e envio de dúvidas e feedbacks.
